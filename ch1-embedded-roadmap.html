1.4 支线判断：RISC-V 现在值得投入吗？

结论 作为第二架构顺手掌握，而不是替代 ARM 从头学。

  • 生态已可用：ESP32-C3/C6、CH32V003/V103、嘉楠 K230、全志 D1 都已铺开。
  • 迁移成本低：FreeRTOS 换掉 port 层即可，上下文切换逻辑同构。
  • 工具链同构：riscv-none-elf-gcc / gdb / OpenOCD 与 ARM 版用法一致。
  • 战略价值：信创与车规市场渗透加快，“ARM 精通 + RISC-V 能上手”是当前较优的简历组合。

1.5

学习本身卡住了，怎么排障？

把“学不会”当成故障：先定位，再修复，别用焦虑代替动作。

环境问题

例程抄了跑不通

根因：板卡版本/引脚差异、库版本差异、漏配宏。

定位路径
  1. diff 你的代码与官方例程，先确认差在哪一行。
  2. 查板卡原理图，核对 LED / 串口引脚是否同名不同脚。
  3. 看 Build Output 的第一条 error，不要只盯着最后一条。
① 工具链版本一致

同一项目内 GCC、CubeMX 生成代码、SDK 版本不要混用。

② 先测供电再上电

新焊接/新接线先用万用表确认无短路，仪器地线共地。

③ 改动要留痕

所有实验用 Git 管理，每次成功后 commit，出问题可 diff 回溯。

FAQ：先学 STM32 还是直接上 Linux 开发板？

先 M 后 A。Cortex-M 裸机阶段你会亲手处理启动文件、向量表、中断现场保存；这些概念到 A 核会变成 ATF / U-Boot / 内核异常向量。没有 M 核直觉直接学 A 核，会处处碰壁且无从调试。

FAQ：需要买正点原子的全套板子吗？

不需要。最低配：一块 F407 系板（含 ST-Link）+ 一块 ESP32-S3 + 24MHz 逻辑分析仪（约 ¥30）。Linux 部分可先用 QEMU 过一遍流程，确定方向后再入 i.MX6ULL 或 RK 板。

FAQ：英语不好能学好嵌入式吗？

手册绕不开（TRM / Datasheet / Errata），但常用技术词约 800 个，句式高度模板化。前 20 章遇到生词就记入个人术语表，两个月后读手册通常比读中文翻译更准。
